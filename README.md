# hydra-user-and-consent-provider-node

| Env Var         | Description                                   |
| --------------- | --------------------------------------------- |
| AUTH_HOSTNAME   | Hostname/URI of Auth Backend                  |
| AUTH_PORT       | E.g. `443`                                    |
| AUTH_PATH       | Defaults to `blank`. E.g. `/admin/v1/domains` |
| AUTH_METHOD     | Defaults to `GET`                             |
| HYDRA_ADMIN_URL | URL to ory admin instance                     |
